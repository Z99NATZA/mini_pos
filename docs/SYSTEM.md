# 📋 ระบบ Mini POS — คำอธิบายระบบ

## ระบบนี้คืออะไร?

**Mini POS** (Mini Point of Sale) คือระบบจัดการร้านค้าสำหรับธุรกิจขนาดเล็ก เช่น ร้านกาแฟ ร้านชานมไข่มุก ร้านอาหาร ที่ต้องการระบบรับออเดอร์และจัดการสินค้าอย่างง่าย รองรับ 2 บทบาท คือ **admin** และ **staff**

---

## 👤 บทบาทผู้ใช้งาน

| บทบาท | ความสามารถ |
|-------|------------|
| **admin** | เข้าถึงทุกหน้า รวมถึงจัดการสินค้า ไซต์ ประเภท ท็อปปิ้ง และผู้ใช้งาน |
| **staff** | เข้าถึงหน้า Dashboard, POS (ขาย), และ Orders (รายการขาย) เท่านั้น |

---

## 🗂️ หน้าและฟีเจอร์

### 1. Login (`/login`)
- กรอก username และ password เพื่อเข้าสู่ระบบ
- ระบบจะสร้างบัญชี `mini_pos` อัตโนมัติหากยังไม่มีในฐานข้อมูล

### 2. Dashboard (`/dashboard`)
- แสดง **ยอดขายวันนี้** (total amount)
- แสดง **จำนวนออเดอร์วันนี้**
- แสดง **จำนวนออเดอร์ทั้งหมด**
- แสดง **จำนวนสินค้า**
- ตาราง **ยอดขาย 7 วันย้อนหลัง**

### 3. POS — ขาย (`/pos`)
หน้าหลักของระบบขาย ใช้สำหรับรับออเดอร์จากลูกค้า
- **กริดสินค้า**: แสดงสินค้าทั้งหมด พร้อมรูปภาพ ชื่อ และราคา
- **ค้นหาสินค้า**: กรองสินค้าด้วยคำค้นหา
- **เพิ่มสินค้าลงตะกร้า**: คลิกสินค้าเพื่อเลือกรายละเอียด:
  - ไซต์ (Size) — มีราคาเพิ่ม เช่น S/M/L
  - ประเภท (Type) — มีราคาเพิ่ม เช่น ร้อน/เย็น/ปั่น
  - ท็อปปิ้ง (Topping) — เลือกได้หลายรายการ มีราคาเพิ่มแต่ละชิ้น
  - จำนวน
- **ตะกร้า**: แสดงรายการที่เลือก, ราคารวม, ลบรายการ
- **ชำระเงิน**: กรอกจำนวนเงินที่รับมา ระบบคำนวณเงินทอนอัตโนมัติ

### 4. Orders — รายการขาย (`/orders`)
ไฟล์ `orders` (คำสั่งซื้อ) คือรายการขายที่สำเร็จแล้วทั้งหมด
- แสดงรายการออเดอร์ทั้งหมด พร้อม: เลขออเดอร์, วันที่/เวลา, ชื่อแคชเชียร์, ยอดรวม, เงินรับ, เงินทอน
- **ดูใบเสร็จ**: คลิกเพื่อดูรายละเอียดออเดอร์ (สินค้า, ไซต์, ประเภท, ท็อปปิ้ง, จำนวน, ราคา)
- **ลบออเดอร์**: ยืนยันก่อนลบ (ลบ cascade ทุก item ที่เกี่ยวข้อง)
- **Pagination**: แสดงทีละ 10 รายการ

### 5. Products — สินค้า (`/products`) 🔒 Admin
จัดการสินค้าในระบบ
- แสดงตารางสินค้า: รูปภาพ, ชื่อ, ราคา, วันที่สร้าง
- **เพิ่มสินค้า**: ชื่อ, ราคา, รูปภาพ (บังคับ)
- **แก้ไขสินค้า**: แก้ไขข้อมูล, เปลี่ยนรูปได้
- **ลบสินค้า**: ยืนยันก่อนลบ
- รองรับ search และ pagination

### 6. Sizes — ไซต์ (`/sizes`) 🔒 Admin
จัดการขนาดสินค้า (เช่น S, M, L) พร้อมราคาเพิ่ม
- เพิ่ม / แก้ไข / ลบ ไซต์

### 7. Types — ประเภท (`/types`) 🔒 Admin
จัดการประเภทสินค้า (เช่น ร้อน, เย็น, ปั่น) พร้อมราคาเพิ่ม
- เพิ่ม / แก้ไข / ลบ ประเภท

### 8. Toppings — ท็อปปิ้ง (`/toppings`) 🔒 Admin
จัดการท็อปปิ้ง (เช่น ไข่มุก, วุ้นมะพร้าว) พร้อมราคา
- เพิ่ม / แก้ไข / ลบ ท็อปปิ้ง

### 9. Users — ผู้ใช้งาน (`/users`) 🔒 Admin
จัดการบัญชีผู้ใช้ในระบบ
- เพิ่มผู้ใช้: username, ชื่อ, รหัสผ่าน, บทบาท (admin/staff), รูปโปรไฟล์
- แก้ไข: เปลี่ยนได้ทุกอย่าง รหัสผ่านเว้นว่างได้ (ไม่เปลี่ยน)
- ลบ: ไม่สามารถลบตัวเองได้, ไม่สามารถลบ admin คนสุดท้ายได้

## 🔢 รูปแบบเลขออเดอร์

```
YYYYMMDD + 5 หลัก (นับจาก 00001)
ตัวอย่าง: 2025061500001, 2025061500002, ...
เริ่มนับใหม่ทุกวัน
```

---

## 💰 รูปแบบตัวเลขเงิน

- **หน้าจอ (blur)**: `12,000.50` — มี comma และ 2 ทศนิยม
- **หน้าจอ (focus)**: `12000.50` — ตัวเลขล้วน เพื่อแก้ไขได้สะดวก
- **ฐานข้อมูล / API**: `12000.50` — ตัวเลขทศนิยม DECIMAL(12,2)
